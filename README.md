# Python DSA Tracker

A Python CLI project for tracking my LeetCode and DSA progress.

## Purpose

I built this project to record solved problems, track patterns, and review my DSA progress in an organized way.

## What It Tracks

Each problem entry includes:

* Problem title
* Platform
* Difficulty
* Pattern
* Status
* Time complexity
* Space complexity
* Review-again flag
* Notes file path

## Example Problem Entry

```json
{
  "id": 1,
  "title": "Two Sum",
  "platform": "LeetCode",
  "difficulty": "Easy",
  "pattern": "Hash Map",
  "status": "Solved",
  "time_complexity": "O(n)",
  "space_complexity": "O(n)",
  "review_again": false,
  "note_file": "notes/two_sum.md"
}
```
